## Tux-Force Wine releases

A Wine release is built on CI each time `develop` is merged into `main`. The tag names the build date and commit,
`wine-YYYYMMDD-<sha7>`. The release has `wine-tux-force-x86_64.tar.xz` (64-bit x86 only) and its `.sha256` file.
xgameruntime is built in, so there is no separate download and nothing to copy into the prefix. The xTux setup
downloads the newest release by itself and checks it against the `.sha256` file.

## Other ways

- **From source:** see [Installation](/guide/installation/) for building xTux and Wine yourself.
- **Development builds:** every successful CI run of the `develop` branch has build artifacts on the repository's
  *Actions* page (GitHub sign-in needed).
- **Flatpak:** `xtux-linux-x86_64.flatpak` is part of every xTux release, on the GNOME runtime; Flathub is planned.

xgameruntime has no separate download: it is part of the Wine build.

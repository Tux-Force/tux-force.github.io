## Other ways

- **From source:** see [Installation](/guide/installation/) for building xTux and Wine yourself.
- **Development builds:** every successful CI run of the `develop` branch has build artifacts on the repository's
  *Actions* page (GitHub sign-in needed).
- **Flatpak:** planned as the first package, with xTux, the launcher and Wine in one app
  ([launcher plan](/project/launcher-plan/#packaging-flatpak-first)).

xgameruntime has no separate download: it is part of the Wine build.

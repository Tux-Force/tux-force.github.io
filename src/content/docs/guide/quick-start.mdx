xTux sets itself up: it downloads the Tux-Force Wine, prepares the Wine prefix and finds your game folders. You only
sign in with your Microsoft account.

**You need:** a 64-bit x86 Linux PC with a Vulkan GPU driver, a Microsoft account that owns the game or has a PC Game
Pass subscription, and the game either installed by the Windows Xbox app on a partition Linux can read, or enough
space to download it.

<Steps>

1. **Install xTux.** Download `xtux-linux-x86_64.flatpak` from the [newest xTux release](/downloads/) and install it:

   ```bash
   flatpak install --user xtux-linux-x86_64.flatpak
   ```

   The Flatpak brings everything the sign-in window needs. Prefer a plain archive?
   See [Installation](/guide/installation/).

2. **Start xTux** from your desktop's app menu, or with `flatpak run io.github.tux_force.xTux`.

3. **Set everything up.** The first start opens **Welcome to xTux**. Choose **Set everything up**: xTux opens
   Microsoft's sign-in window, then downloads the Tux-Force Wine (checked against its SHA-256 file), prepares the
   prefix with DXVK, vkd3d-proton and the certificates games expect, and finds your game folders, including the
   `XboxGames` folders of Windows drives. On the very first sign-in xTux registers your PC with Microsoft and may
   ask for your password once; the [sign-in page](/guide/sign-in/) explains why.

4. **Install if needed.** If the game is not installed yet, choose it in **Store**, select **Install** and add it to
   **Downloads**. See [Launcher](/guide/launcher/#installing-and-deleting-games).

5. **Play.** Press **Play** in the library.

</Steps>

Prefer the terminal? `xtux-cli` without a command shows what is set up, runs the same setup in the terminal and has a
menu to play your games. See [Running games](/guide/running-games/).

Something does not work? See [Troubleshooting](/guide/troubleshooting/), and check the
[compatibility list](/compatibility/) for the game.

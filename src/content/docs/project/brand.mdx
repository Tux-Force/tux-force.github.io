## Typography

Inter Display Black Italic for the wordmark and headlines, Inter for text, JetBrains Mono for code, all under the
SIL Open Font License. The logo files contain the wordmark as outlines, so no font needs to be installed.

## Usage

- Keep the trademark notice when you use the logo: Tux-Force is not affiliated with Microsoft or Xbox.
- Do not combine the logo with Microsoft or Xbox logos in a way that suggests an official product.
- The logo sources and the build script (`tools/build.py`, `tools/export.sh`) are in the
  [website repository](https://github.com/Tux-Force/tux-force.github.io/tree/develop/brand).

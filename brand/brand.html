TUXFORCE

Brand basics for the Tux-Force community fork: a curious penguin taking off, one green palette and a few rules so every repo, README and release looks like it belongs together.

Lime is the brand colour on dark surfaces. On light surfaces use Forest for the symbol and Emerald for “FORCE”, because Lime is too pale on white. The penguin itself stays one colour.

Typography

TUXFORCE

Wordmark and headlines: Inter Display Black Italic, uppercase, tight tracking.

PC GAMES ON LINUX

Taglines: Inter SemiBold, uppercase, wide tracking. Body: Inter Regular. Code: JetBrains Mono.

All fonts are under the SIL Open Font License. The logo files already contain the wordmark as outlines, so they need no installed font.

Usage

Do
  • Keep clear space of half the head height around the logo.
  • Let the penguin fly to the right, towards the text.
  • Put the lime logo on Night or Forest, the light lockup on white.
  • Say “community fork of xodus” in every README.
Don’t
  • Mirror, recolour, stretch or rotate the logo.
  • Combine it with Xbox, Game Pass or Microsoft logos.
  • Use Lime for text on white.
  • Use the pixel mascot as the main logo.
